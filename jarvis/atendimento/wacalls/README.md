# WaCalls no Zérvis

Chamadas e mensagens nativas do WhatsApp em Go puro (whatsmeow, pion e o codec MLow), pareadas por
QR. Origem: [WaCalls](https://github.com/JotaDev66/WaCalls) (MIT, © jotadev66), na versão
modificada no Ligatia por gdautomacao.ia, e trazida para o Zé pelo ADR 0031. Créditos completos em
`THIRD_PARTY.md`.

O Zé compila e mantém este servidor (`jarvis/atendimento/whatsapp.py`): só no endereço local, com
token a cada subida. Para testar à parte: `go vet ./... && go test ./...` nesta pasta.
