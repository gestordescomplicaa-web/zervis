# Comece aqui

O modo imersivo é onde você vê o Zé: ele ouve, pensa e fala no centro da tela, e as esferas
ao redor mostram o que importa agora. Tudo se move com as mãos, pela câmera, ou com o mouse.

## Três coisas para fazer agora

1. **Faça uma pinça no anel** (encoste o polegar no indicador sobre ele). As esferas se abrem.
2. **Diga "Ei Zé"** e peça algo: "me lembra amanhã às nove de ligar para o contador". A esfera
   **Hoje** aparece.
3. **Aperte D** para abrir as configurações. Se a pinça falhar, aperte **K** para calibrar as mãos.

## Como ele cresce

No primeiro dia o imersivo é quase vazio, de propósito. Cada esfera aparece quando tem algo a
mostrar: **Hoje** com um lembrete ou uma frente de trabalho, **Trabalho** com uma sessão de código,
**Acervo** com uma imagem ou um modelo 3D na pasta do Zé.

O que se configura (modelos, voz, perfil, chaves) fica no painel. Aqui é para ver.
