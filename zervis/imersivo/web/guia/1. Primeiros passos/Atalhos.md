# Atalhos

A **engrenagem** no canto superior esquerdo abre as configurações, com esta lista no topo.

| Tecla | O que faz |
|---|---|
| **D** | Abre e fecha as configurações |
| **K** | Calibra as mãos (guiado na tela) |
| **Shift + K** | Volta as mãos à calibração padrão |
| **B** | Aumenta o brilho da câmera |
| **Shift + B** | Diminui o brilho da câmera |
| **T** | Troca as cores |
| **F** | Troca o fundo: a câmera ou o escuro animado (as mãos continuam sendo lidas) |
| **/** | Escrever para o Zé, sem falar |
| **R** | Recarrega a tela (relê o Guia e o Acervo) |
| **C** | Troca a câmera |
| **Esc** | Fecha o que estiver aberto |
