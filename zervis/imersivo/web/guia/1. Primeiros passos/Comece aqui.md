# Comece aqui

O modo imersivo é onde você vê o Zé: ele ouve, pensa e fala na tela, e mostra ao lado dele o
que você pede. Tudo se move com as mãos, pela câmera, ou com o mouse.

## Três coisas para fazer agora

1. **Diga "Ei Zé, me explica"** um assunto: "me explica juros compostos". Ele vai para o canto e
   monta a explicação com gráficos, etapas e 3D. "Se apresenta" mostra os números dele.
2. **Peça uma tela pelo nome**: "abre o Mapa", "mostra o meu dia", "abre o Guia". Faça uma pinça
   (encoste o polegar no indicador) para pegar, mover ou jogar fora o que aparecer.
3. **Toque na engrenagem** (canto superior esquerdo) ou aperte **D** para abrir as configurações. Se a pinça falhar, aperte **K** para calibrar as mãos.

## Como ele cresce

No primeiro dia o imersivo é quase vazio, de propósito. As telas ganham conteúdo com o uso:
**Hoje** com um lembrete ou uma frente de trabalho, **Trabalho** com uma sessão de código,
**Acervo** com uma imagem ou um modelo 3D na pasta do Zé.

O que se configura (modelos, voz, perfil, chaves) fica no painel. Aqui é para ver.
