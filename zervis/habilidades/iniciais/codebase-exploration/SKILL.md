# Explorar o repositório

## Do meu jeito
- Confirme as instruções e os padrões do projeto antes de propor uma solução.
- Siga o fluxo real no código; não deduza comportamento só pelo nome de um arquivo.
- Mantenha a exploração proporcional à tarefa.

## Passos
1. Leia as instruções locais, o README e a documentação diretamente relacionada à tarefa.
2. Localize os pontos de entrada, os módulos envolvidos e os testes existentes.
3. Siga os dados e chamadas entre esses pontos para entender o comportamento atual.
4. Resuma os arquivos relevantes, os contratos e as verificações adequadas.

## Pronto quando
- A área responsável e seus limites estão identificados.
- A proposta respeita as convenções já usadas no repositório.
- Nenhum arquivo foi alterado só para explorar o código.
